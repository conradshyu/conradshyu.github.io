About

CS::Statistics is a free online tool for statistical analysis. You can run the analysis such as Linear Regression, Logistic Regression, and One-Way ANOVA. You can also use this tool to generate figures and charts. Please note that this tool is not intended for professional use and should not be used for critical applications. It is designed for educational purposes and to help users understand basic statistical concepts.

To get acquainted with the tool, you should start with the Tutorial page with the example data from Import Data and then Load Example Data. The tutorials are based on the example dataset. After you have learned the basics, you can upload your own data from Open a XLSX File ... in Import Data.

If you have any questions or suggestions, please feel free to contact us.
