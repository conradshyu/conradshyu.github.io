Synopsis

CS::Statistics is a free online tool for statistical analysis. You can run analyses such as Linear Regression, Logistic Regression, and One-Way ANOVA. You can also generate charts such as Line Chart, Pie Chart, or even Radar Chart. If you do not have your own dataset, please use the one in the dropdown menu Import Data/Load Example Data. The tutorials will be based on this example dataset.

How to run univariate analysis?

Univariate analysis is a basic kind of analysis technique for statistical data. Here the data contains just one variable and does not have to deal with the relationship of a cause and effect. Like for example consider a survey of a classroom. The analysts would want to count the number of boys and girls in the room. The data here simply talks about the number which is a single variable and the variable quantity. The main objective of the univariate analysis is to describe the data in order to find out the patterns in the data. This is done by looking at the mean, mode, median, standard deviation, dispersion, etc.

To run an analysis, first run Load Example Data and then select the procedure from the dropdown menu Univariate. The application will automatically add a tab with the results. You can also run multiple analyses at the same time. The results will be displayed in separate tabs, and you can switch between them by clicking on the tab. The results will be displayed with a figure and table.

Univariate: Linear Regression

Linear Regression is a statistical procedure that quantifies the relation between one or more quantitative (predictor) variables \( X_i \) so that a response variable \( Y \) can be predicted from the other, or others. The model is expressed as as \( Y = \beta_0 + \beta_i X_i + \epsilon_i, \), where \( Y \) is the value of the response variable, \( \beta_0 \) and \( \beta_i \) coefficients, \( X_i \) value of the predictor in the ith trial, and \( \epsilon_i \) random error with \( E \left( \epsilon_i \right) = \sigma^2 \).

To run linear regression, click Univariate and then select Linear Regression. You should see a dialog box with options to select variables for the response (\( Y \)) and predictor(s) (\( X_i \)). Drag and drop abnormal as the response variable, tuberculosis and pneumonia as the predictor variables. Click the Run button.

The figure shows the linear regression model with abnormal as the response variable, tuberculosis and pneumonia as the predictor (or independent) variables. In the chart, the red dots indicate the observed values of the response variable, and blue predicted values. The fitted line is the best estimate of the relationship between the predictor variable(s) and the response variable. The slope of the line is the change in the response variable for a one-unit change in the predictor variable. The intercept is the value of the response variable when the predictor variable is zero. The regression model fits quite well with \( R^2 = 0.8178 \) (maximum 1.0). The coefficient (1.6866) for pneumonia is much larger than that of tuberculosis. This indicates that tuberculosis is a much better predictor for the response variable abnormal.

Univariate: Logistic Regression

Logistic Regression examines the relationship between predictor variables (or independent variables) \( X_i \) and a categorical (i.e., with two possible outcomes, such as success/failure, yes/no, or 1/0) response variable \( Y \). The logistic function is expressed as: \[ \ln \left[ \frac{p(x)}{1 - p(x)} \right] = \beta_0 + \beta_1 x \text{ or equivalently, } p(x) = \frac{e^{\beta_0 + \beta_1 x}}{1 + e^{\beta_0 + \beta_1 x}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}} \] where \( \beta_0 \) the intercept (it is the vertical intercept or \( y \)-intercept of the line \( y = \beta_0 + \beta_1 x \)).

To run logistic regression, click Univariate and then select Logistic Regression. You should see a dialog box with options to select variables for the category (\( Y \)) and predictor(s) (\( X_i \)). Drag and drop feature as the response category, tuberculosis and weight as the predictor variables. Click the Run button.

The figure shows the logistic regression model with feature as the response category, and tuberculosisand weight as the predictor variables. The model does not fit the data well with the score of 0.5676. Both tuberculosis and weight are marginally correlate to the outcome of feature. This can partially attributes to the fact the number of data points in each category is not well balanced. There are far more samples in the first category (labeled as 0) than the second category (labeled as 1). Therefore, the logistic regression model is not able to predict the category well.

Univariate: One-Way ANOVA

One-Way ANOVA compares the means between groups and determines whether any of those means are statistically significantly different from each other. Specifically, it tests the null hypothesis \( H_0: \mu_1 = \mu_2 = \ldots = \mu_k \) against the alternative hypothesis \( H_a: \) at least one \( \mu_i \) is different, where \( \mu_i \) is the mean of the ith group. The test statistic (\( F\) distribution) is \[ F = \frac{MS_{\text{between}}}{MS_{\text{within}}} = \frac{\frac{SS_{\text{between}}}{k - 1}}{\frac{SS_{\text{within}}}{N - k}} \] where \( MS_{\text{between}} \) is the mean square between groups, \( MS_{\text{within}} \) is the mean square within groups, \( SS_{\text{between}} \) is the sum of squares between groups, \( SS_{\text{within}} \) is the sum of squares within groups, \( k \) is the number of groups, and \( N \) is the total number of observations.

To run one-way ANOVA, click Univariate and then select One-Way ANOVA. You should see a dialog box with options select variables for the group for comparison. Select abnormal, tuberculosis, and pneumonia for the group. Click the Run button.

The figure shows the one-way ANOVA that compares the group with abnormal, tuberculosis, and pneumonia. The box chart shows that these three variables are statistically similar but abnormal with a slightly larger variance. The \( p \)-value is 0.8780, which indicates that the analysis fails to reject the null hypothesis, specifically \( H_0: \mu_{\text{abnormal}} = \mu_{\text{tuberculosis}} = \mu_{\text{pneumonia}} \).

Univariate: Student's \( t \)-Test One Sample

Student's \( t \)-Test One Sample (or Student's \( t \)-test) is a statistical test that evaluates if a sample mean is significantly different from a known population mean, i.e., \( \mu = 0 \). The null hypothesis states there is no significant difference between the sample mean and the population mean (\( \mu = 0 \)). The alternative hypothesis assumes there a significant difference between the sample mean and population mean, as indicated by the \( p \) value.

To run the one-sample \( t \)-test, click Univariate, Student's \( t \)-Test, and then select One Sample. You should see a dialog box with options to select a variable as the population for comparison. Select abnormal as the population for comparison. Click the Run button.

The figure shows the Student's \( t \)-test with one sample abnormal. The \( t \) statistic is 0.9972 with \( p \) value of 0.3219. The analysis indicates that the sample mean is not statistically different from the population mean of \( \mu = 0 \). The analysis also calculates the summary statistics such as mean (average), median, and variance.

Univariate: Student's \( t \)-Test Two Samples

Student's \( t \)-Test Two Samples (also know as the independent samples \( t \)-test) evaluates whether the unknown population means of two groups are equal or not. This test assumes data are independent and randomly sampled from two normal populations and two independent groups hae equal variances.

To run the two-sample \( t \)-test, click Univariate, Student's \( t \)-Test, and then select Two Sample. You should see a dialog box with options to select a variable as the population for comparison. Select abnormal and tuberculosis as the populations for comparison. Click the Run button.

The figure shows two-sample \( t \)-test that evaluates population means of abnormal and tuberculosis. The analysis shows that there is no statistically difference between the population means of abnormal and tuberculosis with \( t \) statistic of 0.4307 and \( p \) value 0.6673.

Univariate: Student's \( t \)-Test Paired Samples

Student's \( t \)-Test Paired Samples, also known as a dependent samples \( t \)-test, evaluates if there is a significant difference between the means of two related (paired) populations. It is commonly used to compare measurements from the sample subjects under different conditions. The null hypothesis typically assumes that the true mean difference between the paired samples is zero, meaning there's no significant difference. The test assumes that the differences between the paired observations are normally distributed.

To run the paired-sample \( t \)-test, click Univariate, Student's \( t \)-Test, and then select Paired Sample. You should see a dialog box with options to select a variable as the population for comparison. Select abnormal and tuberculosis as the populations for comparison. Click the Run button.

The figure shows the paired-sample \( t \)-test that evaluates population means of abnormal and tuberculosis. The analysis shows that there is no statistically difference between the population means of abnormal and tuberculosis with \( t \) statistic of 0.6766 and \( p \) value 0.5008.

How to run multivariate analysis?

Multivariate statistical analysis refers to techniques that simultaneously exams multiple variables in relation to the subjects under investigations with the aim of identifying or clarifying the relationship between them. These techniques have been broadly classified as dependence techniques, which explore the relationship between one ore more dependent variables and their independent predictors, and interdependence techniques., that make no such distinction but treat all variables equally in a search for underlying relationships.

The results will be displayed with a figure and table.

Multivariate: Cluster Analysis (K-Means)

K-means clustering is an unsupervised learning algorithm that groups unlabeled data points into groups or clusters. It is a iterative, centroid-based clustering algorithm that partitions a dataset into similar groups based on the distance between their centroids. The centroid, or cluster center, is either the mean or median of all the points within the cluster depending on the characteristics of the data. The objective is to minimize the sum of distances between data points and their assigned clusters. Data points that are nearest to a centroid are grouped together within the same category. A higher k value, or the number of clusters, signifies smaller clusters with greater detail, while a lower k values results in larger clusters with less detail.

Multivariate: Multidimensional Scaling (MDS)

Multidimensional Scaling (MDS) is a technique that is used to create visual representation of the pattern of proximities (similarities, dissimilarities, or distances) among a set of objects. For example, given a matrix of distances between cities, MDS can be used to generate a map of the cities in two dimensions. MDS is frequently used in consumer research where researchers have measures of perceptions about brands, tastes, or other product attributes. It is applicable to many other areas where one is interested in visualizing the proximity of objects based on a set of attributes or proximities.

Multivariate: Multivariate Analysis of Variance (MANOVA)

Multivariate Analysis of Variance (MANOVA) examines the dependence relationship between a set of dependent measures across a set of groups. The technique examines the relationship between several categorical independent variables, and two or more dependent variables. Typically, MANOVA is based on a specific hypothesis of relationship between dependent measures and is often used to validate experimental designs. The null hypothesis is of no difference between categories (e.g., different treatments). In this technique, the independent variables are categorical, and the dependent variable is not. The limitation of this method is sample size, usually needing 15-20 observations. However, too many observations (over 30) often cause overfitting. The model fit is determined by examining the mean vector across groups. If there is a significant difference in the means, the null hypothesis can be rejected, and treatment differences can be determined.

Multivariate: Principal Components Analysis (PCA)

Principal component analysis (PCA) reduces the number of dimensions in large datasets to principal components that retain most of the original information. It does this by transforming potentially correlated variables into a smaller set of variables, called principal components. PCA extracts the most informative features from large datasets while preserving the most relevant information from the initial dataset. This reduces model complexity as the addition of each new feature negatively impacts model performance, which is also commonly referred to as the curse of dimensionality. PCA also minimizes or altogether eliminates common issues such as multicollinearity and overfitting. Multicollinearity occurs when two or more independent variables are highly correlated with one another, which can be problematic for causal modeling. Overfit models will generalize poorly to new data, diminishing their value altogether.

How to run ensemble learning?

Ensemble learning is a machine learning technique that combines multiple individual models (also known as weak learners) to produce a more accurate and robust prediction than any single model could achieve alone. It leverages the collective intelligence of multiple models to overcome the limitations and biases of individual models. Ensemble learning rests on the principle that a collectivity of learners yields greater overall accuracy than an individual learner.

You can also run multiple analyses at the same time. The results will be displayed in separate tabs, and you can switch between them by clicking on the tab. The results will be displayed with a figure and table.

Ensemble: Decision Tree

A decision tree is a nonparametric supervised learning algorithm, which is utilized for both classification and regression tasks. It has a hierarchical tree structure, which consists of a root node, branches, internal nodes and leaf nodes. Decision tree learning employs a divide and conquers strategy by conducting a greedy search to identify the optimal split points within a tree. This process of splitting is then repeated in a top-down, recursive manner until all, or most records have been classified under specific class labels.

Ensemble: Naïve Bayes

Naïve Bayes is a supervised machine learning algorithm, specifically a classification algorithm, that uses probability and Bayes' theorem to predict the category a data point belongs to. It's called naïve because it assumes that the features used in the prediction are independent of each other, even if that's not always true in reality. This simplification makes it computationally efficient, especially for large datasets, and allows it to perform well in various applications like spam filtering and text classification.

Ensemble: Random Forest

The random forest algorithm is the combination of tree predictors such that each tree depends on the values of a random vector sampled independently and with the same distribution for all trees in the forest. It can be applied to different machine learning tasks, in particular, classification and regression. Random forest uses an ensemble of decision trees as a basis and therefore has all advantages of decision trees, such as high accuracy, easy usage, and no necessity of scaling data. Moreover, it also has a very important additional benefit, namely perseverance of overfitting (unlike simple decision tree).

Ensemble: Support Vector Machine (SVM)

A support vector machine (SVM) is a supervised machine learning algorithm that classifies data by finding an optimal line or hyperplane that maximizes the distance between each class in a high dimensional space. Technically, the primary objective of the SVM algorithm is to identify a hyperplane that distinguishably segregates the data points of different classes. The hyperplane is localized in such a manner that the largest margin separates the classes under consideration.
