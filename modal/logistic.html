Univariate: Logistic Regression

Logistic Regression is a statistical method that estimates the probability of a categorical, binary outcome based on one more more independent variables. It utilizes a S-shaped sigmoid function to map predictions to a probability between 0 and 1.

NOTE: Drag and drop only one variable with non-numerical values (categorical) for the response variable (Y). You can select multiple variables with numerical values for the predictors (Xi).
