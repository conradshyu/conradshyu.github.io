Chart: Scatter

A scatter chart is a type of plot or mathematical diagram using Cartesian coordinates to display values for typically two variables for a set of data points. The data are displayed as a collection of points, each having an X and Y coordinate corresponding to the values of the two variables.

NOTE: Drag and drop only one variable with numerical values for the label on the X-axis. You can select multiple variables with numerical values for the Y-axis.
